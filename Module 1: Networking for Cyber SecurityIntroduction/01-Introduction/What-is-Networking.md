# What is Networking?

## Overview

Networking is the process of connecting two or more devices so they can communicate and share data, resources, and services. These devices may include computers, servers, routers, switches, smartphones, printers, and IoT devices.

In cybersecurity, understanding networking is essential because almost every cyberattack occurs over a network. Security analysts use networking knowledge to identify malicious traffic, investigate incidents, detect unauthorized access, and protect systems.

---

## Why Networking is Important

Without networking:

- Computers cannot communicate with each other.
- Websites cannot be accessed.
- Emails cannot be sent or received.
- Cloud services cannot function.
- Online banking and digital payments would not work.

Networking forms the foundation of modern communication and information sharing.

---

## Basic Components of a Network

### 1. Host

A host is any device connected to a network that can send or receive data.

Examples:
- Laptop
- Desktop Computer
- Mobile Phone
- Server
- Smart TV

---

### 2. Server

A server is a computer that provides services or resources to other devices (clients) on the network.

Examples:
- Web Server
- Mail Server
- Database Server
- File Server

---

### 3. Client

A client is a device that requests services or data from a server.

Example:
Your browser requests a webpage from a web server.

---

### 4. Router

A router connects multiple networks and forwards data packets between them.

Functions:
- Connects Local Network to the Internet
- Assigns routes
- Performs NAT
- Filters traffic

---

### 5. Switch

A switch connects devices within the same Local Area Network (LAN).

Functions:
- Learns MAC addresses
- Reduces collisions
- Improves network efficiency

---

### 6. Firewall

A firewall monitors incoming and outgoing traffic based on predefined security rules.

Functions:
- Blocks unauthorized access
- Allows trusted traffic
- Prevents attacks

---

### 7. Access Point

Provides wireless connectivity to devices.

Examples:
- Home Wi-Fi Router
- Office Wireless Access Point

---

Example:

↓

---

## Example Scenario

You open your browser and visit:

https://www.google.com

The following occurs:

1. Browser sends request
2. DNS resolves the domain name
3. Router forwards packet
4. ISP routes traffic
5. Google's server receives request
6. Server sends webpage
7. Browser displays webpage

---

## Networking in Cybersecurity

Cybersecurity professionals use networking knowledge to:

- Analyze packet captures
- Detect malware communication
- Investigate suspicious IP addresses
- Identify brute-force attacks
- Monitor unusual traffic
- Detect data exfiltration
- Investigate phishing attacks

---

## Common Networking Devices

| Device | Purpose |
|---------|----------|
| Router | Connects different networks |
| Switch | Connects devices inside LAN |
| Firewall | Filters network traffic |
| Hub | Broadcasts traffic to all ports |
| Access Point | Wireless connectivity |
| Modem | Connects to ISP |

---

## Key Takeaways

- Networking enables communication between devices.
- Routers connect different networks.
- Switches connect devices inside the same network.
- Firewalls secure the network.
- Networking is one of the most important foundations of cybersecurity.
